# Image Converter

이미지 배경 제거·크기 조절·형식 변환 도구(Windows)의 설치 파일 배포용 저장소입니다. 내려받기는 **Releases** 에서 합니다.

## 이용 조건

Copyright © 2026 Suyong Lim. All rights reserved.

- **개인의 비영리 목적 사용은 무료**입니다.
- 회사·기관·단체의 업무 또는 영리 목적의 사용은 저작권자의 허락이 필요합니다.
- 허락 없이 다시 배포·판매·대여하거나 고쳐서 배포할 수 없습니다.
- "있는 그대로" 제공하며 어떤 보증도 하지 않습니다. 관련 법이 허용하는 범위에서, 사용으로 생긴 손해에 책임을 지지 않습니다.

이 조건은 이 저장소에서 내려받는 모든 버전에 적용합니다. 1.1.1 다음 버전부터는 전체 이용 안내를 설치할 때 화면에 보여 주고 설치 폴더에 `이용안내.txt` 로 넣습니다(1.1.0·1.1.1 설치 파일에는 이 안내가 들어 있지 않습니다). 함께 배포하는 제3자 구성 요소와 AI 모델에는 각자의 라이선스가 적용되며, 목록과 원문은 설치 폴더의 `licenses` 폴더에 있습니다.

이미지는 PC 안에서 처리하고 외부로 보내지 않습니다. 앱은 새 버전 확인과 내려받기를 위해 GitHub 에 접속합니다.

문의와 이용 허락 요청은 [Issues](https://github.com/suyonglim/image-converter-release/issues) 에 남겨 주세요.
